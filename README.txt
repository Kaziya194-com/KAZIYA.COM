KAZIYA Website — setup guide

FILES
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)

TEST IT ON YOUR PHONE / COMPUTER
1. Download and extract kaziya_website.zip.
2. Open index.html in Chrome or another browser.
3. Test the order form. Submit opens WhatsApp with a pre-filled order message.
4. Make sure WhatsApp is available on the device and the number is correct.

PUBLISH IT ONLINE FOR FREE (Netlify Drop)
1. Extract the ZIP on your computer.
2. Open https://app.netlify.com/drop in a browser.
3. Sign in if asked, then drag the folder containing index.html into the drop area.
4. Netlify will give you a public website URL. You can share that URL with customers.

IMPORTANT
- WhatsApp number is set in index.html as 94728090293 (international format, no plus or spaces).
- Customers must tap Send in WhatsApp; this does not silently send messages.
- A selected reference image is NOT automatically attached to WhatsApp. The filename appears in the message; the customer should attach the actual image in the WhatsApp chat.
- Product names, service names, prices and gallery panels are examples. Edit index.html to add your real products, prices, and images.
- This is a front-end website. It does not store orders in a database or accept online payments.
